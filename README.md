# Select Co.

Projeto de e-commerce Select Co. — sneakers e streetwear.

## Estado atual

O repositório contém uma captura HTML do site exportada/salva, e não o código-fonte completo confirmado da aplicação. Consulte [a auditoria inicial](docs/auditoria-inicial.md) antes de tentar executar ou modificar o HTML.

## Trabalho seguro

- `main`: versão original preservada.
- `estrutura-selectco`: branch isolada para auditoria e reorganização.
- Não substituir a captura original até que uma alternativa tenha sido reconstruída e validada.
